Oracle Cloud's $3 million donation of Arm64 compute credits to CNCF projects is improving architecture support across the ecosystem, where over 50% of new AWS instances and 33% of Azure instances now run on Arm64 CPUs. The CNCF Infra team provisions OCI instances as GitHub Actions runners, letting projects like OpenTelemetry, Falco, and containerd run native Arm64 CI testing without capacity constraints. The article outlines how projects request credits, with usage guardrails initially around $5,000 USD/month to keep shared access sustainable.
